## 3. COMPONENTES DO CODIGO

### 3.1 Imports (linhas 1-16)
tkinter, PIL, shutil, webbrowser, json, os, sys, sqlite3, subprocess, threading, time, random, datetime, pygame

### 3.2 Config (linhas 22-37)
Constantes de cores e tamanhos. Cards: 260x340px. Sidebar: 380px.

### 3.3 STREAMINGS_DB (linhas 41-76)
32 servicos com: url, category, icon, color, deep_link, url_template, top_content

### 3.4 NexusDB (linhas 153-188)
SQLite com tabelas: history (id, service_name, content_title, timestamp), stats (service_name, total_watches, last_watched)

### 3.5 StreamingOpener (linhas 191-210)
Deep links: tenta protocolo nativo (netflix://, youtube://), fallback para URL web.

### 3.6 GamepadManager (linhas 213-248)
Thread separada para polling de gamepad via pygame. 20ms polling.

### 3.7 BigPictureApp (linhas 251-750)
 Classe principal com:
 - build_ui(): Layout completo com top bar, content area, sidebar
 - Navegacao: Left/Right/Up/Down/Enter/Escape
 - render_home(): Recentes, Favoritos, categorias
 - render_section(): Cards em linha horizontal
 - create_card(): Card com cor do servico, logo, top 3 titulos
 - Sidebar: Historico, Favoritos, Tema, Resolucao, Gamepad
 - Context menu: Abrir, Favorito, Logo, Excluir, Copiar URL
 - Adicionar streaming: Formulario completo
 - Resolucao: 5 opcoes
 - Tema: 8 cores

## 5. RECURSOS NOVOS (v5.0)

1. **UI Big Picture**: Cards grandes com cor do servico, layout horizontal
2. **SQLite**: Historico e estatisticas persistentes
3. **Deep Links**: Protocolos nativos (netflix://, youtube://, etc)
4. **Sidebar**: Painel lateral estilo Steam
5. **Gamepad**: Suporte via pygame (XInput)
6. **Navegacao por teclado**: Setas, Enter, Esc
7. **Top 3 titulos**: Cada card mostra os 3 principais titulos
8. **Cores por servico**: Netflix=vermelho, YouTube=verde, etc
