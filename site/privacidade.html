Política de Privacidade — Nexus

Última atualização: setembro/2026

1. Resumo

O Nexus não possui servidores próprios e não coleta seus dados de uso. Tudo o que você configura fica no seu computador.

2. Dados locais (só no seu PC)

  • Configurações e favoritos (settings.json): preferências, cores, favoritos.
  • Histórico (nexus.db): o que você assistiu/jogou, para Recentes e estatísticas.
  • Perfil do navegador embutido: logins, cookies e senhas dos streamings, guardados no seu Windows e nunca enviados a nós.
  • Chave Pro: a chave de licença digitada no app, validada direto com a API do Gumroad.

3. Dados da compra

Pagamentos e e-mails de recibo são tratados exclusivamente pelo Gumroad, sob a política de privacidade deles. Não recebemos seu cartão nem sua senha.

4. Rede local

O recurso "controle pelo celular" comunica o app com o seu telefone apenas dentro da sua rede Wi-Fi (com código de pareamento). Nada sai para a internet.

5. Atualizações

O app consulta a API pública do GitHub para verificar novas versões (sem enviar dados pessoais).

6. Seus direitos

Você pode apagar todos os dados locais a qualquer momento: exclua settings.json, nexus.db e a pasta de perfil do navegador em %LOCALAPPDATA%\Nexus. Para dados da compra, fale com o Gumroad.
